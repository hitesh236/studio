# **App Name**: HicksTable

## Core Features:

- Virtual Scroll HTML Table: Displays an HTML table with scroll functionality for handling 10,000+ records, designed for a single data set
- Summary Card: Top-level summary metrics which displays four summary "cards" related to the data (average values, top 10%, etc.)
- Data Expansion: Row expansion to display a detailed data set for the corresponding data row
- Text-based Filter: Basic filter to quickly find your desired search by rows in the HTML Table
- Hick's Law: follow the principle Hick's Law, in UX design, dictates that the more choices a user has, the longer it will take them to make a decision

## Style Guidelines:

- Primary color: A sophisticated Teal (#03A6A1) to evoke trust and stability in an enterprise environment.
- Background color: A very dark gray (#121826) to maintain focus and reduce eye strain during extended use.
- Accent color: A vibrant purple (#9B51E0) to draw attention to interactive elements and highlight data insights.
- Font: 'Inter', a grotesque-style sans-serif, provides a modern, machined, objective look suitable for an enterprise data display application.
- Need option for a table to show compact and normal view
